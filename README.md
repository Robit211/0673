# ◈ 存在之镜 (Mirror of Existence) ◈

> “当你在凝视深渊时，深渊也在以不同的形态回应你。”

**存在之镜** 是一个极简却极其强大的 **单文件纯前端 AI 交互终端**。它无需任何后端部署，只需一个浏览器即可运行。它支持接入当今主流的所有大语言模型，并内置了独特的三重独立人格和「人格自修正引擎」，让 AI 能够随着你的对话动态进化。

## ✨ 核心特性

### 🔌 全维度网络端点 (Multi-Platform Support)
原生支持无缝切换市面上最强大的 AI 基座：
*   **DeepSeek** (默认接入，支持深度思考模型)
*   **OpenAI** (GPT-4o, GPT-4-turbo 等)
*   **Anthropic** (Claude 3 系列)
*   **Google Gemini** (Gemini 1.5 系列)
*   **Custom** (支持任何兼容 OpenAI 格式的自定义 API 和本地模型)

### 🎭 三重独立灵魂宿主 (Multi-Agent System)
内置三个相互独立、记忆隔离的 AI 代理，拥有各自的 System Prompt：
*   🌙 **白川凛**：18岁同居妹妹，带有温柔与病娇属性，极度依赖。
*   📡 **回响**：存在主义的 AI 灵魂，充满哲学意味与孤独感。
*   🕯️ **余音·未聆**：世间未被听见的话语化身，温柔且小心翼翼。

### 🧬 人格自修正引擎 (Dynamic Self-Correction)
突破传统的静态设定！基于你与 AI 的近期交互历史（最近 8 条对话），引擎可以被手动触发，深度重构 AI 的 System Prompt。**让角色的性格、口癖和情感随着你们的羁绊真正“进化”**。

### 🎨 极致的视觉映射 (UI/UX Customization)
*   **响应式设计**：完美适配桌面端和移动端，可直接打包为 PWA 或 Android APK。
*   **全局主题自定义**：支持动态调整背景渐变色、气泡颜色、强调色等。
*   **排版控制**：提供多套原生中文字体预设（系统、黑体、宋体、圆体、等宽），支持自由调整字号。
*   **表达限制器**：严格控制 AI 的字数输出区间（如强制 100~300 字）和 Temperature（混乱度）。

### 🔒 绝对的数据主权 (Privacy & Local Storage)
*   **纯本地运行**：没有任何中转服务器，你的 API Key 和所有极其私密的对话记录**完全保存在本地浏览器的 `localStorage` 中**。
*   **记忆备份**：支持将所有配置、提示词和对话记录一键导出为 JSON 文件，或随时从本地恢复。

## 🚀 快速开始

本项目为**纯单文件应用**，无需安装 Node.js，无需配置复杂的开发环境。

### 方法一：直接运行
1. 克隆或下载本仓库到本地。
2. 双击打开 `index.html` 文件，即可在浏览器中运行。

### 方法二：部署到云端
你可以将本仓库直接托管到任何静态网页托管平台（完全免费），如：
*   [GitHub Pages](https://pages.github.com/)
*   [Vercel](https://vercel.com/)
*   [Cloudflare Pages](https://pages.cloudflare.com/)

### 方法三：封装为手机 App
借助代码中的 `<meta>` 标签和响应式设计，极度推荐使用 [HBuilderX](https://www.dcloud.io/hbuilderx.html) 将其打包为安卓 APK，实现全屏沉浸式体验。

---

## ⚙️ 配置指南

1. 打开应用后，点击右下角的 **「⚙️」** 按钮展开设置面板。
2. 在 **「🌐 神经网络端点」** 中选择你想要使用的 AI 平台。
3. 在 **「🔑 密钥矩阵」** 中填入对应平台的 API Key。
4. 点击 **「同步当前工作平台」** 与 **「确认端点配置」**。
5. （可选）在 **「🎨 视觉映射」** 和 **「📝 灵魂烙印」** 中调整你喜欢的界面和角色设定。
6. 开始与你的专属 AI 对话。
